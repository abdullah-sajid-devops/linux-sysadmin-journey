# Day 37 — Essential Linux Commands I Keep Coming Back To

Today was a lighter day — instead of new content, I put together a quick reference of the Linux commands I've found myself using again and again since starting this journey. Sharing it here in case it helps other beginners too.

## File & Directory Navigation
- `ls -la` — list everything, including hidden files, with full details
- `cd`, `pwd` — move around and confirm where you are
- `find` and `locate` — two ways to hunt down a file (live search vs. cached database)

## Viewing & Editing Files
- `cat`, `less` — quickly view file contents
- `nano` / `vim` — edit files directly in the terminal

## Permissions & Ownership
- `chmod`, `chown` — control who can read, write, or execute a file
- `ls -l` — the fastest way to check current permissions

## Process & System Monitoring
- `ps aux`, `top`, `htop` — see what's actually running on your system
- `df -h`, `du -h` — check disk space, human-readable

## Networking Essentials
- `ping`, `curl`, `ssh` — test connections, fetch data, and connect to remote systems

## Getting Help When You're Stuck
- `man <command>` — the full manual
- `<command> --help` — a quick syntax reminder
- `whatis` and `apropos` — when you can't quite remember the command's name

## Takeaway
None of these are flashy, but they show up constantly — in daily practice, troubleshooting, and real DevOps work. Sometimes the most useful thing isn't learning something new, it's making sure the fundamentals are rock solid.
