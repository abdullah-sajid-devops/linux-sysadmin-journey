## Beyond Man Pages: GNU info Documentation
While `man` pages are great for quick reference, `info` provides a structured, book-like reading experience with connected nodes (hyperlinks):
- **Navigation:** `TAB` jumps to the next link, `u` goes up one level, `l` returns to the last viewed location, `q` quits
- Running `info` without arguments opens the top-level directory node — the master Table of Contents for Linux

## Quick Terminal Assistance with --help
Appending `--help` (e.g., `cat --help`) gives an instant summary of command syntax and flags directly on the command line — no need to open the full manual.

## Third-Party Documentation & README Files
Linux stores vendor docs, package guides, and detailed README files for complex system services at:
- **Primary location:** `/usr/share/doc`
- A must-know path for any System Administrator or DevOps engineer setting up new software packages
