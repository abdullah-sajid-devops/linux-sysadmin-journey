## GNU info — beyond man pages

Unlike man pages, `info` gives you a structured, book-like reading experience with connected nodes you can navigate between.

- **TAB** — jumps to the next link
- **u** — goes up one level
- **l** — returns to your last viewed location
- **q** — quits
- Running `info` with no arguments opens the top-level directory — the master table of contents

## Quick terminal assistance with `--help`

When you just need a quick syntax or flag check, appending `--help` (e.g. `cat --help`) gives an instant summary on the command line.

## Third-party documentation & README files

- **Primary location:** `/usr/share/doc`
- Vendor docs, package guides and README files for installed software
