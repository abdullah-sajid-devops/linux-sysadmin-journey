# Day 40 of Cisco Linux Essentials Course

Today I covered a set of commands that are genuinely used every day in a sysadmin's routine.

## mv Command
Used to move a file from one location to another — and also used to rename files.

Key flags:
- `-v` (Verbose) — shows exactly what got moved
- `-n` (No clobber) — won't overwrite existing files
- `-i` (Interactive) — asks for confirmation before overwriting

## touch Command
Used to create an empty file in Linux. Creates a zero-byte file, ready to be written into.

## rm Command
Used to delete files. **Important:** Linux has no Recycle Bin — files deleted with `rm` are gone permanently.

Key flags:
- `-i` (Interactive) — confirms before deleting
- `-r` (Recursive) — deletes a folder along with everything inside it

## mkdir Command
Used to create new directories.

## rmdir Command
Used to delete empty folders.

Simple commands, but they're the backbone of daily file management on any Linux system.
