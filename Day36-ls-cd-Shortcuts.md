## The ls Command Has Way More Flags Than I Thought

When I first started, I only knew `ls` had a few flags — `-a`, `-l`, `-s`. Today I learned it has many more: `-d`, `-R`, `-r`, `-a`, `-l`, `-s`, `-S` — each doing something different.

The most surprising part: these flags can be combined into a single command, like `ls -lsa` or `ls -Rsa`, to get multiple behaviors at once.

## The cd Command Isn't as Basic as It Seems

`cd` feels like the most basic command any fresher learns. But there are far more ways to use it than I realized. I used to think you had to go back one directory at a time with `cd ..`, then step into another directory one by one. Today I learned you can jump directly from one directory straight into another with a single command — no repeated back-and-forth needed.

## Key Takeaway

The Linux terminal is genuinely faster than any GUI — once you actually know how to use it properly.
